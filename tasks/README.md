# Задачи на развитие

Каталог задач проекта «Кеске». Один файл — одна задача.

## Правила

1. **Текст задачи пишет только владелец.** Всё, что находится между маркерами
   `ЗОНА ВЛАДЕЛЬЦА` и `КОНЕЦ ЗОНЫ ВЛАДЕЛЬЦА`, агент не меняет — ни формулировки,
   ни критерии, ни приоритет.
2. **Агент только дописывает отчёты.** Ниже маркера `ЗОНА АГЕНТА` агент добавляет
   новый блок отчёта и ничего не удаляет из предыдущих.
3. **Статус и готовность ведутся в таблице ниже.** Файл задачи — единственный источник
   её текста, эта таблица — единственный источник статуса.
4. **Новую задачу** удобнее всего копировать из `_template.md` под следующим свободным номером:
   `NNN-korotkiy-slug.md`. Номер не переиспользуется.
5. **Завершённую задачу** агент помечает `done` и оставляет файл на месте: история отчётов
   важнее чистоты каталога.

## Статусы

| Статус | Значение |
|---|---|
| `todo` | сформулирована, не начата |
| `in-progress` | агент работает прямо сейчас |
| `review` | сделано, ждёт проверки владельца |
| `blocked` | нужен ответ владельца или внешнее условие |
| `done` | проверено и принято |
