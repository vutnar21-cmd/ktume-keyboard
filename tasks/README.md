# Задачи на развитие

Каталог задач проекта «Кеске». Один файл — одна задача.

## Правила

1. **Текст задачи пишет только владелец.** Всё, что находится между маркерами
   `ЗОНА ВЛАДЕЛЬЦА` и `КОНЕЦ ЗОНЫ ВЛАДЕЛЬЦА`, агент не меняет — ни формулировки,
   ни критерии, ни приоритет.
2. **Агент только дописывает отчёты.** Ниже маркера `ЗОНА АГЕНТА` агент добавляет
   новый блок отчёта и ничего не удаляет из предыдущих.
3. **Статус живёт на kanban-доске `keske`, а не в этом файле.** Здесь — только тексты
   спецификаций; ход выполнения смотреть на доске.
4. **Новую задачу** удобнее всего копировать из `_template.md` под следующим свободным номером:
   `NNN-korotkiy-slug.md`. Номер не переиспользуется. Карточка на доске создаётся
   с тем же номером в заголовке.
5. **Завершённую задачу** агент оставляет файл на месте: история отчётов важнее чистоты каталога.

## Kanban-доска

```
Доска:  keske  («Кеске — Android клавиатура»)
Рабочая директория по умолчанию: этот проект
```

| Команда | Что делает |
|---|---|
| `hermes kanban list` | все карточки и статусы |
| `hermes kanban show t_xxxx` | карточка: описание, комментарии, история запусков |
| `hermes kanban unblock t_xxxx` | взять в работу — воркер стартует в течение минуты |
| `hermes kanban complete t_xxxx` | принять работу |
| `hermes kanban comment t_xxxx "текст"` | заметка к карточке |
| `hermes kanban block t_xxxx "причина"` | припарковать |

| Статус на доске | Значение |
|---|---|
| `blocked` | припаркована: ждёт старта или решения владельца |
| `ready` | готова к запуску |
| `running` | воркер работает прямо сейчас |
| `review` | сделано, ждёт приёмки владельца |
| `done` | проверено и принято |

Автозапуск ревью отключён (`kanban.review_dispatch: false`) — приёмка всегда за владельцем.
Автозапуск задач включён: `unblock` означает «делай».
