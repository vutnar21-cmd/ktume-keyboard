## Задача

Расстояние между клавишами по умолчанию — 8 (сейчас 3).

## Критерии готовности

- [ ] `keyGapDp` по умолчанию = 8
- [ ] Новое значение применяется на устройстве, где уже сохранены настройки
- [ ] Подпись ползунка в настройках говорит «по умолч. 8»

## Ограничения

- Ширина клавиши считается как `(ширина − gap × (колонок − 1)) / колонок`, поэтому при
  8 dp клавиши станут уже; проверить, что 10 клавиш в ряду не сжимаются ниже читаемого.
- Ключ хранилища версионирован: при смене дефолта суффикс нужно поднять (`_v5` → `_v6`).

## Отчёты

### 2026-10-23 · 100 % · статус `review`

**Сделано.** `keyGapDp` по умолчанию = **8** (было 3).

- `KeyboardPreferences`: `keyGapDp = 8f`.
- `PreferencesRepository`: ключ `key_gap_dp_v5` → `key_gap_dp_v6`, дефолт чтения `8f` —
  новое значение применится на устройстве, где уже сохранены настройки.
- Подпись ползунка: «по умолч. 8».

**Предупреждение (из консультации с Argon).** При 10 клавишах в ряду и ширине экрана 360 dp
клавиша сжимается с ~33 dp до ~29 dp: `(360 − 8×9) / 10`. На узких экранах текст может
начать обрезаться. Если это проявится — вернуть 5–6 dp или сделать gap адаптивным
(меньше на узких экранах).

**Проверено:** тест дефолтов обновлён (`8f`), сборка и 21 тест зелёные, lint 0.
