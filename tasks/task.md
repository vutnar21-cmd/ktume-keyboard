Единый локальный бэклог для человека и ИИ-агента (без облачных трекеров).

## Как вести этот файл

- Правила проекта, команды сборки и критерий «Готово» — в [`AGENTS.md`](../AGENTS.md).
- **Поток:** `Входящие (Inbox)` → `В очереди (Backlog)` → `В работе (In Progress)` → `Готово (Done)` → [`tasks/archive.md`](archive.md) (когда `Done` перерастает ~25–30 пунктов).
- **Разборы и история отчётов:** `tasks/specs/NNN-slug.md`. Скриншоты к задачам: `tasks/img/` (`img/…`).
- **Маркеры:** `(!)` — срочно / баг; `(?)` — развилка (код не писать, спросить); `(src?)` — проверить по источнику; `(~)` — на вырост (в `DECISIONS.md`); `(@)` — проверить живьём человеку (не закрывать без подтверждения); `(x)` — табу (`отклонено`); `(sic)` — оставить как есть.
