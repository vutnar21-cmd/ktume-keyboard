## Задача

Фича. Экспериментальная автозамена опечаток в чувашском и русском тексте.

Клавиатура по локальному частотному словарю находит слово, отличающееся от набранного на 1–2 правки
(замена, вставка, пропуск, перестановка соседних букв), и **сразу исправляет** его при вводе
разделителя. Примеры: «превет» → «привет», «сегоднч» → «сегодня», «сак» → «ҫак».

Решения владельца (2026-11-04):

- автозамена — экспериментальная функция на вкладке «Эксперименты», **выключена по умолчанию**;
- исправление автоматически по разделителю: пробел, `. , ! ? ; : ) » "` и перевод строки (`Enter`
  в многострочных полях);
- **откат первым `⌫`** сразу после исправления: возвращается набранное слово, разделитель остаётся,
  в этом поле слово больше не исправляется;
- языки: чувашский и русский сразу; языки автозамены выбираются в настройках;
- **личный словарь** сразу: включаемый пункт «Запоминать отменённые слова», просмотр и удаление слов,
  кнопка очистки; хранится только на устройстве, не пополняется в режиме инкогнито приложений
  (`IME_FLAG_NO_PERSONALIZED_LEARNING`), не сбрасывается кнопкой «Сбросить все настройки»;
- ленты подсказок в верхней панели в этой итерации **нет** (инвариант № 3 `AGENT.md` в силе);
  вопрос о ленте отложен.

## Критерии готовности

- [ ] Тумблер «Автозамена опечаток» на вкладке «Эксперименты», выключен по умолчанию
- [ ] Исправление по пробелу, знакам препинания и `Enter` в многострочных полях
- [ ] Первый `⌫` сразу после исправления возвращает набранное слово, разделитель остаётся
- [ ] Чувашский и русский словари (слово + частота), источник и лицензия указаны, словари
      пересобираются скриптом
- [ ] Выбор языков автозамены в настройках
- [ ] Личный словарь: «Запоминать отменённые слова», просмотр, удаление слов, очистка; только локально,
      не пополняется в инкогнито, не сбрасывается общим сбросом настроек
- [ ] Чувашские слова не «исправляются» в русские (и наоборот): слово из любого словаря не трогается
- [ ] Пароли, адреса, e-mail, поля без подсказок, аббревиатуры и токены с цифрами/латиницей не исправляются
- [ ] Есть unit-тесты на поиск кандидатов, цены правок, решение об автозамене и откат
- [ ] Проверено на устройстве владельцем

## Ограничения

- Эксперимент живёт на вкладке «Эксперименты» и выключен по умолчанию.
- Чувашские слова не должны «исправляться» в русские.
- Ленты подсказок в верхней панели в этой итерации не добавлять: только исправление.
- Всё локально: словари встроены в приложение, личный словарь хранится только на устройстве,
  без сети и облачных сервисов.

## Отчёты

### 2026-11-02 · Готовность: 5 % (план)

- **Решения владельца (2026-11-02, в чате):** объём расширен — **подсказки слов + исправление опечаток**
  для чувашского и русского; исправление **автоматически по пробелу** с откатом первым `⌫`; **личный
  словарь** только на телефоне. Это расходится с ограничением выше («подсказки не добавлять») —
  текст задачи в зоне владельца нужно обновить.
- **Источники слов (проверено 2026-11-02):**
  - русский — [FrequencyWords](https://github.com/hermitdave/FrequencyWords) `ru_50k.txt`
    (OpenSubtitles 2018, 50 000 словоформ с частотами), лицензия CC BY-SA 4.0;
  - чувашский — готового частотного списка нет: строим сами из дампа чувашской Википедии
    (59 тыс. статей, ~8,5 млн слов, CC BY-SA 4.0), чистим проверкой по словарю Hunspell
    [Chuvash_Spell 1.06](http://hunspell.chv.su/) (GPL-3.0+ / LGPL-3.0+ / MPL-1.1);
  - CC BY-SA распространяется на сами списки слов (отдельные файлы в `assets/`), код остаётся Apache-2.0;
    атрибуция — в `THIRD_PARTY_NOTICES.md` и на вкладке «Система».
- **План:**
  1. `scripts/dictionaries/` — сборка `assets/dict/ru.tsv` и `cv.tsv` (слово + частота, ~30–50 тыс. на язык).
  2. `data/` — чистый движок без Android: дописывание по префиксу и поиск исправлений с расстоянием
     Дамерау–Левенштейна ≤ 2, где замена соседней на раскладке клавиши стоит дешевле; язык словаря —
     по текущей раскладке.
  3. Защита чувашских слов: слово, найденное в любом словаре (чувашском, русском, личном), не исправляется;
     автозамена только при высокой уверенности (длина ≥ 3, расстояние 1–2, частота кандидата сильно выше).
  4. Верхняя панель: до 3 подсказок (средняя — лучшая, жирная, если применится по пробелу); стрелки
     курсора — когда подсказок нет.
  5. Автозамена по пробелу и знакам препинания; первый `⌫` сразу после неё возвращает набранное слово
     и запоминает его.
  6. Личный словарь: слова, которые пользователь оставил как есть, — только локально; не учится в полях
     паролей и при `IME_FLAG_NO_PERSONALIZED_LEARNING` (инкогнито); очистка в настройках.
  7. Настройки на вкладке «Ввод»: подсказки, автозамена, личный словарь (+ очистить).
  8. Тесты: расстояние, кандидаты, решение об автозамене, чувашские слова не превращаются в русские.
- **Что осталось:** обновить текст задачи (владелец), затем реализация по плану.

### 2026-11-04 · Готовность: 60 %

- **Решения владельца (2026-11-04, в чате):** автозамена — эксперимент, выключена по умолчанию;
  исправление по разделителю с откатом первым `⌫`; чувашский и русский сразу с выбором языков; личный
  словарь сразу; **ленты подсказок нет** (инвариант № 3 в силе, вопрос отложен). Владелец разрешил
  агенту обновить зону владельца — текст задачи выше приведён к этим решениям.
- **Сделано (ветка `feature/013-autocorrect`):**
  - `data/autocorrect/` — чистый движок без Android-UI:
    - `WordTrie.kt` — компактное префиксное дерево в плоских массивах, поиск кандидатов со взвешенным
      расстоянием Дамерау–Левенштейна (с отсечением ветвей по допустимой цене);
    - `TypoCostModel.kt` — цены правок: обычная правка `2`, «дешёвая» `1` — соседняя клавиша текущей
      раскладки, пропущенный надстрочный знак (`а/ӑ`, `е/ӗ/ё/э`, `с/ҫ`, `у/ӳ`, `и/й`, `ь/ъ/ы`, `ш/щ`),
      сдвоенная или потерянная двойная буква; надбавка за правку первой буквы (`firstLetterExtra = 1`);
    - `Autocorrector.kt` — решение об исправлении: слово ≥ 3 букв, только кириллица; ВСЕ ЗАГЛАВНЫЕ и
      смешанный регистр не трогаются; слово из любого словаря (чувашского, русского) или личного словаря
      не трогается; допустимая цена по длине `1 / 2 / 3 / 4` (≤ 3, ≤ 5, ≤ 8, длиннее); оценка
      `ln(частота / всего) − 2,3 · цена` + бонус словарю текущей раскладки (`ln(10)`); порог выгоды над
      гипотезой редкого слова вне словаря (`minGain = 2,0`) и порог разрыва между кандидатами
      (`minMargin = 1,5`); русская обсценная лексика не подставляется. Политика полей как в AOSP LatinIME:
      только `TYPE_CLASS_TEXT`, не пароль / URI / e-mail / фильтр, без `NO_SUGGESTIONS`, однострочное поле —
      только с `AUTO_CORRECT`; токены с цифрами, латиницей, `@ # /` и т. п. не исправляются;
    - `AutocorrectSession.kt` — откат первым `⌫` и список отклонённых слов текущего поля;
    - `AutocorrectEngine.kt` — фоновая загрузка `assets/dict/cv.tsv` и `ru.tsv` только при включённом
      эксперименте и выбранном языке, выгрузка при выключении.
  - Интеграция: `KesjeImeService` (`onCommitText`, `onBackspace`, `onEnter`), тестовое поле настроек
    (`SettingsPreviewBench`) тоже исправляет, блок настроек `SettingsAutocorrect.kt` на вкладке
    «Эксперименты»: тумблер, языки, «Запоминать отменённые слова», список слов личного словаря с
    удалением, очистка с подтверждением.
  - Настройки: `experimentalAutocorrect = false`, `autocorrectLangs = {cv, ru}`,
    `autocorrectLearnWords = true`; ключи DataStore `exp_autocorrect_v1`, `autocorrect_langs_v1`,
    `autocorrect_learn_v1`, личный словарь — `personal_words_v1` (`PreferencesState.personalWords`),
    не пополняется при `IME_FLAG_NO_PERSONALIZED_LEARNING`, не сбрасывается «Сбросить все настройки».
  - Словари (`scripts/dictionaries/build_dictionaries.py`, нужны `pyarrow` и `spylls`; кэш исходников
    `scripts/dictionaries/.cache/` в `.gitignore`):
    - `cv.tsv` — 160 000 словоформ (частота ≥ 4) из корпуса Hugging Face
      [alexantonov/chuvash_mono](https://huggingface.co/datasets/alexantonov/chuvash_mono)
      (~3,1 млн предложений, CC0-1.0); «ложная латиница» `ăĕçÿŭ` приведена к `ӑӗҫӳ`; убраны написания
      без надстрочных знаков, если вариант со знаками чаще в ≥ 30 раз (21 201 форма, напр. «весем» при
      «вӗсем»), а также опечатки самого корпуса (98 216 форм), отвергнутые на этапе сборки проверкой
      Hunspell [Chuvash_Spell 1.13](http://hunspell.chv.su/) (`chuvash_spell_dictionary-1.13.xpi`), если
      в одной правке есть слово в ≥ 20 раз частотнее;
    - `ru.tsv` — 160 000 словоформ (частота ≥ 17) из
      [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) `ru_full.txt`
      (OpenSubtitles 2018, CC BY-SA 4.0), только кириллица, нижний регистр; на этапе сборки убраны
      опечатки субтитров (173 990 форм, напр. «пожалйста», «здраствуйте», «сдесь»), отвергнутые
      проверкой Hunspell `ru_RU` из LibreOffice при наличии соседа в ≥ 20 раз частотнее;
    - размер — ~3,2 МБ каждый; атрибуция — в `THIRD_PARTY_NOTICES.md` (сами словари Hunspell используются
      только при сборке и в приложение не входят).
  - Также исследованы открытые источники по чувашскому языку:

      Николая Плотникова [hunspell.chv.su](http://hunspell.chv.su/) доступны расширения Firefox
      (`chuvash_spell_dictionary-1.13.xpi`) и LibreOffice (`Chuvash_Spell-1.11.oxt`) — именно этот словарь

    - оцифрованные архивы периодики `chuvash-data/*` на Hugging Face («Ялав», «Капкӑн», «Чӑваш коммуни») и
      дамп `cvwiki` (CC BY-SA 4.0).
  - Документация: `AGENT.md` (карта кода, инвариант № 15, веха), `THIRD_PARTY_NOTICES.md`,
