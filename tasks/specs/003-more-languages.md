## Задача

Опциональная задача: добавить раскладки других языков народов Поволжья или соседних регионов.
Кандидаты обсуждаемы — например, татарский, марийский, удмуртский, башкирский.

Для каждого языка нужно: раскладка, таблица Long-Press, подпись подтипа в `method.xml`,
пункт в списке активных раскладок, запись в `getCandidatePool`.

## Критерии готовности

- [ ] Утверждён список языков
- [ ] Для каждого — раскладка и таблица долгого нажатия
- [ ] Подтип виден в системном выборе клавиатур
- [ ] Тест: Hex-упаковка не теряет символы для новой раскладки

## Ограничения

- `KeyboardLang` — перечисление; новый язык добавляется туда и во все `when`-ветки
  (`getDefaultRows`, `getCandidatePool`, `getLongPressVariants`, `dictionarySuggestions`).
- Код языка (`code`) попадает в `enabledLayouts` — менять его после релиза нельзя,
  иначе слетят сохранённые настройки.
