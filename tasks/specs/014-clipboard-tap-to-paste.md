## Задача

Вставка из буфера обмена: тапом на надпись, а не по кнопке «Вставить».

То есть весь текст в полосе буфера становится кликабельной зоной: тап по нему вставляет
содержимое. Отдельная кнопка не нужна.

## Критерии готовности

- [ ] Тап по тексту вставляет содержимое буфера
- [ ] Кнопка «Вставить» убрана
- [ ] Пустой буфер: полоса не реагирует на тап (или показывает подсказку)
- [ ] Семантика для TalkBack: текст озвучивается как действие «вставить»

## Ограничения

- Нормализация `ăĕçÿ → ӑӗҫӳ` при вставке сохраняется (неявная, см. задачу 010).
- Системный буфер не перезаписывается.
