## Задача

Остаток находок код-ревью после итерации 5. Блокеры (P1) уже исправлены, здесь — значимое
и мелкое. Порядок внутри списка — по ожидаемой пользе.

### Значимое

- [ ] **Режим клавиатуры не сбрасывается при смене поля.** Открыл Numpad или смайлы, перешёл
      в другое приложение — там тот же режим. Caps Lock тоже переезжает.
      (`KeyboardScreen.kt`, `keyboardMode` / `shiftState`; нужен сброс по `onStartInputView`.)
- [ ] **Удаление слова свайпом по ⌫.** Разделителем считается только пробел: перевод строки
      не видит, стирает через `\n` и до 64 символов, выделение игнорируется.
      (`KesjeImeService.kt`, `onDeleteWord` и `onReplaceCurrentWord`.)
- [ ] **Свайп-⌫ не работает после 380 мс автоповтора** — жест молча игнорируется,
      потому что автоповтор уже начался (`repeatCount == 0` в условии).
      (`KeyboardScreen.kt`, `BackspaceKey`.)
- [ ] **Запись настроек на каждое движение ползунка.** Нужен debounce (~250 мс) или
      `onValueChangeFinished`, иначе десятки полных перезаписей файла за один проход.
      (`SettingsActivity.kt`, `ThemePalettes.kt`.)
- [ ] **Тестовое поле может поднять системную клавиатуру поверх превью.** `hide()` — не гарантия;
      надёжнее `readOnly` + `showKeyboardOnFocus = false`.

### Мелкое

- [ ] `Paint` / `Path` / `CornerPathEffect` создаются в draw-пути каждой соты — вынести в `remember`.
- [ ] `remember` вместо `rememberSaveable`: поворот экрана стирает текст тестового поля и вкладку.
- [ ] Fallback палитры — `SoftSage`, хотя дефолт `obsidian_forest` (`KesjePalettes.byId`).
- [ ] Порог свайпа курсора по пробелу задан в пикселях (`18f`) вместо dp.
- [ ] Шаг выбора в попапе Long-Press `34 dp` при фактической ячейке `40 dp` — подсветка отстаёт.
- [ ] `Vibrator` запрашивается через `getSystemService` на каждое нажатие.
- [ ] Первый показ клавиатуры рендерится с дефолтными настройками — заметный «прыжок» палитры.
- [ ] В режиме сот `showNumberRow` молча игнорируется (решить: скрывать тумблер или пояснять).

### Процесс

- [ ] **Инициализировать git-репозиторий** и закоммитить текущее состояние: сейчас истории нет,
      откатить неудачную правку нечем.
