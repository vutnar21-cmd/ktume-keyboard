## Задача

Фича. Микрословарь: исправление 1–2 неправильных букв в русском.

Идея: небольшой словарь частых русских слов, по которому клавиатура находит слово,
отличающееся на 1–2 символа, и предлагает (или сразу применяет) исправление.
Пример: «превет» → «привет», «сегоднч» → «сегодня».

## Критерии готовности

- [ ] Определено: предлагать или исправлять автоматически
- [ ] Определён размер словаря и откуда он берётся
- [ ] Описано поведение для чувашских слов (не ломать их)
- [ ] Есть тесты на расстояние Левенштейна / поиск кандидатов

## Ограничения

- Словарные подсказки в верхней панели не добавлять (см. задачу 006): только исправление.
- Чувашские слова не должны «исправляться» в русские.
- Экспериментальные функции живут на вкладке «Эксперименты».
