## Задача

Зазор между клавишами — чисто визуальная штука. Если палец попадает в зазор, тап должен
засчитываться той клавише, что ближе.

Сейчас зазор «мёртвый»: хитбокс равен видимой клавише, попадание в щель не делает ничего.

Реализация — не «ближайшая по расстоянию», а детерминированно: каждая клавиша владеет
половиной зазора с каждой стороны, хитбоксы стыкуются ровно посередине щели.

## Критерии готовности

- [ ] Хитбокс шире видимой клавиши на половину зазора с каждой стороны
- [ ] Видимая клавиша рисуется внутри хитбокса с отступом `gap / 2`
- [ ] Работает для букв, цифрового ряда, нижнего ряда, цифровой панели
- [ ] Минимальный тач-таргет не меньше 48 dp по обеим осям
- [ ] Семантика и Long-Press не сломаны

## Ограничения

- **Hex-режим не трогать**: там зазоры нормальные и своя геометрия с `clipToBounds`.
- Клавиши с разными весами (пробел 3.4, дефис 0.85) должны получать хитбокс строго по весу,
  иначе «ближайшая» окажется не той.
- Двойной пробел и свайп курсора по пробелу сохраняются.
